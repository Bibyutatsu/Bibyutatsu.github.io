# Bibhash Mitra - Portfolio Website (v3.0)

[![GitHub Pages](https://img.shields.io/badge/Hosted%20on-GitHub%20Pages-blue?logo=github)](https://bibyutatsu.github.io)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE.md)

A high-performance, immersive portfolio website for **Bibhash Mitra**, Senior Data Scientist & AI/ML Expert. This version features a complete redesign with a focus on **immersive 3D visuals**, **dynamic themes**, and **modern web APIs**.

🔗 **Live Site**: [bibyutatsu.github.io](https://bibyutatsu.github.io)

---

## ✨ Features

### Visual & Immersive Design
- **🎮 Multiple Dynamic Themes** - Switch between **Dark**, **Light**, **Batman** (Gotham Noir), **Cyberpunk** (Neon Pink), and **Ocean** (Deep Teal).
- **🌌 Three.js Hero Background** - An interactive 3D particle field that responds to mouse movement.
- **🖱️ Custom Cursor** - A smooth, reactive cursor dot and ring for enhanced interactivity.
- **📜 Scroll-Driven Progress Bar** - Pure CSS scroll progress indicator.
- **🎨 Cinematic Typography** - Space Grotesk (headings), Inter (body), Fira Code (code/tags), and Bangers (Batman theme).

### User Experience
- **🚀 Ultra-Fast Performance** - Zero external frameworks (no Bootstrap, no jQuery). Built with pure Vanilla JS and CSS.
- **📱 Responsive Layout** - Fluid design that adapts perfectly from mobile screens to ultra-wide monitors.
- **🔍 Reveal Animations** - Optimized IntersectionObserver-based fade-ins.
